## 原实测与公开版的范围

- 原实测范围：固定模型在线推理、43 个计时进程、4 个 Profiler 进程、36 个微基准分组、四组完整质量验收。

- 原在线服务曾完成请求功能验证；旧 TorchAir HTTP 进程退出测试出现过需强制结束的情况，因此本教程默认演示 eager 服务。不能把旧记录说成图模式服务生命周期已全部通过。

数据审计脚本从公开样本重算各进程 P50/P95、分组三轮统计、微基准汇总及 Profiler kernel 数与 Computing/gap，检查稳态重编译与 cgroup 节流记录。它不能替代重新采样，也不能证明未公开的原始 trace。

可在仓库根目录重复执行：

~~~powershell
python -m unittest discover -s tests -v
python tools/verify_results.py
python -m pip install -r requirements-figures.txt
python tools/plot_results.py
~~~

运行 CPU 测试需要 torch、transformers 和 numpy；Windows 不需要安装 torch_npu。正式 NPU 环境按 [教程](tutorial.md) 准备，不能把本地 CPU 测试环境当成服务器配套版本。
